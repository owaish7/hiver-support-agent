THE FAILURE THAT MATTERS

4 of 7 human-needed
cases were missed.

English keyword rules missed real security and billing complaints. A confident intent prediction did not make the routing decision safe.

The judge isn’t ground truth.

60 replies have human ratings; 51 also have valid judge scores. On those 51, the judge accepted 44 replies (86.3%) and the human accepted 40 (78.4%). Agreement κ = 0.599. Five replies the judge accepted were rejected by the human.

POLICY EXPLORER

What does more caution cost?

Re-route cached predictions with different runtime thresholds. Original escalations stay escalated; new gates can only add human review. This is a post-hoc exploration of the test set, not a new held-out result or a calibrated risk score.

03 / BUILT TO BE QUESTIONED

What’s behind the interface.

Read the full research report ↗
01

Ground the draft

Local MiniLM embeddings retrieve similar historical support conversations. The generator classifies the message and drafts from retrieved examples; the exact evidence is available beside each result.

02

Separate the decisions

Message-based escalation rules and runtime uncertainty gates are distinct. Hand-labelled escalation decisions remain the reference, so extra caution has a visible precision cost.

03

Check the evaluator

A separate model family judges grounding, relevance, and overpromising. Human ratings on 60 replies test that judge. One-rater labels and modest sample sizes limit what can be concluded.

Scope & limitations

The source contains 150 labelled messages: 60 development and 90 test. Rare classes were intentionally oversampled. Conversations are historical, from 2017. Model confidence is self-reported and uncalibrated. The original report and some configuration comments contain legacy counts; this interface uses the actual committed files.

The recorded-case explorer replays the original pipeline’s outputs. The separate live workspace uses Gemini with BM25 retrieval over demo or visitor-supplied support policies. It has not been evaluated on this historical benchmark. Threshold changes and visitor reviews do not modify the original labels or evaluation.
